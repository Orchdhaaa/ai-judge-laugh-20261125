One office joke, one line: "I told my boss I was drowning in work, so he sent me a calendar invite titled 'Swimming Lessons'." The setup is the everyday complaint of drowning in work that everyone in an office knows; the turn is the boss answering with a calendar invite instead of help, and the punchline lands last in the invite's title, literalising the metaphor.

## Run it

```sh
node main.ts
```

`main.ts` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is one line of 1–200 characters with no dash, and that it has the drowning-in-work setup, the calendar-invite turn, and the punchline ending on 'Swimming Lessons'.
